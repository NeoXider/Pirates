# Pirate's Dungeon Adventure

A thrilling Unity-based adventure game where players take on the role of a brave pirate exploring mysterious dungeons in search of treasure.

## 🎮 Game Overview

Navigate through treacherous dungeons filled with traps, puzzles, and mysteries as you search for the legendary treasure chest. Use your wit and various interactive items to overcome challenges and survive the dungeon's dangers.

### Core Features

- **Dynamic Character Control**: Fluid pirate character movement and animation system
- **Interactive Environment**: Various interactive objects and mechanisms to solve puzzles
- **Combat System**: Engage in combat with weapons and items found throughout the dungeon
- **Health System**: Manage your character's health while avoiding traps and enemies
- **Puzzle Elements**: Solve various dungeon puzzles using interactive objects
- **Treasure Hunt**: Search for the ultimate treasure chest while collecting other valuable items

## 🔧 Technical Architecture

The game is built using Unity and follows a component-based architecture for maximum modularity and maintainability.

### Key Components

- **Player System**: Character control, animations, and health management
- **Interactive System**: Handles all interactive objects and puzzle elements
- **Weapon System**: Manages combat mechanics and weapon behavior
- **UI System**: In-game interface and player feedback
- **Audio System**: Sound effects and ambient audio
- **Money System**: Treasure and currency management
- **Spawner System**: Handles object and enemy spawning

## 🎯 Game Objective

Guide your pirate through the dungeon, solving puzzles and avoiding traps, to find the legendary treasure chest. Use interactive objects wisely and manage your resources to survive the journey.

## 🛠️ Development Status

Currently in active development. Core systems including player movement, health management, and basic interactions are implemented.

---

*Built with Unity Engine and C#*

# Приключения Пирата в Подземелье

Захватывающая игра на Unity, где игроки берут на себя роль отважного пирата, исследующего таинственные подземелья в поисках сокровищ.

## 🎮 Обзор Игры

Исследуйте опасные подземелья, наполненные ловушками, загадками и тайнами в поисках легендарного сундука с сокровищами. Используйте свою смекалку и различные интерактивные предметы, чтобы преодолевать препятствия и выживать в опасностях подземелья.

### Основные Особенности

- **Динамичное Управление Персонажем**: Плавная система движения и анимации пирата
- **Интерактивное Окружение**: Различные интерактивные объекты и механизмы для решения головоломок
- **Боевая Система**: Сражайтесь с помощью оружия и предметов, найденных в подземелье
- **Система Здоровья**: Управляйте здоровьем персонажа, избегая ловушек и врагов
- **Элементы Головоломок**: Решайте различные загадки подземелья с помощью интерактивных предметов
- **Поиск Сокровищ**: Ищите главный сундук с сокровищами, собирая по пути другие ценные предметы

## 🔧 Техническая Архитектура

Игра создана на Unity и следует компонентной архитектуре для максимальной модульности и удобства поддержки.

### Ключевые Компоненты

- **Система Игрока**: Управление персонажем, анимации и управление здоровьем
- **Интерактивная Система**: Обработка всех интерактивных объектов и элементов головоломок
- **Система Оружия**: Управление боевой механикой и поведением оружия
- **Система UI**: Игровой интерфейс и обратная связь с игроком
- **Аудио Система**: Звуковые эффекты и фоновая музыка
- **Денежная Система**: Управление сокровищами и валютой
- **Система Спавна**: Управление появлением объектов и врагов

## 🎯 Цель Игры

Проведите пирата через подземелье, решая головоломки и избегая ловушек, чтобы найти легендарный сундук с сокровищами. Разумно используйте интерактивные предметы и управляйте ресурсами для выживания в путешествии.

## 🛠️ Статус Разработки

В настоящее время находится в активной разработке. Реализованы основные системы, включая движение игрока, управление здоровьем и базовые взаимодействия.
